THOUGHT LEADERSHIP

Insights from building production AI infrastructure without cloud dependencies

PART 1 OF 6

The $0 AI Platform: Why We Chose Pain Over Platforms

We could have used EKS or GKE. Instead, we spent weeks wrestling with bare metal, debugging Cilium, and writing a 1,400-line bootstrap script. Total cloud spend: $0/month. Total control: 100%.

Key Insight

"If the solution requires 'just sign up for Service X,' it's not a solution. It's a dependency."

PART 2 OF 6

Git as the Entire Product

Documentation drifts. Code doesn't. By making the repo the deployable system (not documentation about it), we eliminated "ask Steve" knowledge silos forever.

Key Insight

"If it's not in the repo, it doesn't exist. There's no 'I'll document this later.'"

PART 3 OF 6

The VM Iteration Loop: DevOps Without the Cloud

Our CI/CD pipeline is virsh snapshot-revert. Revert. Clone. Test. Repeat. Under 15 minutes from code change to verified working, without cloud CI minutes.

Key Insight

"Test from outside, not inside. Localhost tests miss network, firewall, and bind-mount issues."

PART 4 OF 6

Breaking the Single Node: HA Without Handwaving

Everything worked on one node. Then we added a second. This is what breaks when you go from demo to production—networking, storage, state consensus.

Key Insight

"HA isn't just 'more servers.' It's no SPOF, automatic failover, and state consistency."

PART 5 OF 6

GPUs Don't Share Nicely: Multi-Model Reality

184GB VRAM sounds like a lot until you try to run two 70B models. vLLM doesn't hot-swap. Model switching means restart. Real constraints, real solutions.

Key Insight

"The demo vs production problem: which of our 9 models handles this request?"

PART 6 OF 6

Agents on Local LLMs: The SPRINT Cliff

10-step agent loop: ~15 seconds with cloud API, ~5 minutes with local 70B model. That's not a rounding error—it's a different product. Here's what actually works.

Key Insight

"We're not pretending local equals cloud. We're documenting where the gaps are."

LESSONS LEARNED

What I tried that didn't work—and why documenting failure matters

File Copying Instead of Symlinks REJECTED
What We Tried

Copying files from git repo to /opt/ai-pod/ during deployment.

What We Learned

Sync drift is inevitable. Multiple sources of truth = no source of truth. Symlinks maintain single source.

React Dashboard REJECTED
What We Considered

Building dashboard in React for component reuse and modern DX.

What We Learned

Build steps add complexity. Partners can't easily modify. "Edit file, refresh browser" wins for training systems.

Timer-Based Conversation Commits REJECTED
What We Tried

Committing AI conversations on a timer (every 30 minutes).

What We Learned

Misses critical compaction events. Event-driven hooks beat timer-based for state preservation.

# One-command deployment
#!/bin/bash

deploy_infrastructure() {
    echo "Installing k3s..."
    curl -sfL https://get.k3s.io | sh -

    echo "Deploying Cilium CNI..."
    cilium install --wait

    echo "Starting vLLM..."
    kubectl apply -f vllm-deployment.yaml
}

# Model switching API
@app.route('/api/model/switch')
def switch_model(model_name):
    """Hot-swap between 9 LLMs"""

    # Update vLLM deployment
    patch = {
        "spec": {
            "containers": [{
                "env": [{
                    "name": "MODEL",
                    "value": model_name
                }]
            }]
        }
    }
    k8s.patch_deployment(patch)
    return {"status": "switching"}

ENGINEERING WISDOM

Hard-won lessons from production AI infrastructure

Silent Failures Are Worst

"A crash tells you something is wrong. A silent failure tells you nothing. We'd rather have an ugly error message than a pretty button that does nothing."

Git Is The Product

"If it's not in the repo, it doesn't exist. The repository IS the system — not documentation about a system, but the actual deployable system itself."

Record Your Dead Ends

"Every approach we tried that failed is documented. A dead end isn't a failure — it's information that prevents future wasted time."

Fresh Clone Testing

"Your development environment lies to you. The only valid test is: Does it work on a machine that has NEVER seen this code before?"

Complexity Is Borrowed

"Every bit of complexity you add today is borrowed from someone's future time. Before adding complexity, ask: Who will pay the interest?"

Event-Driven > Timers

"Timer-based protection has a fatal flaw: important events don't respect your schedule. Don't save every 30 minutes. Save when something HAPPENS."

TECHNICAL DEEP DIVES

Detailed breakdowns of key architectural decisions

🔗

Symlink Architecture

Live system runs from symlinks pointing to the git repo. Edit the repo, the system updates. No deployment step for dashboard changes.

🧠

CLAUDE.md Pattern

AI assistants read a single file at session start that contains everything needed to understand and work on the project.

🔄

VM Iteration Loop

QEMU snapshot → deploy → test → revert. Poor-man's CI/CD without cloud infrastructure. Under 15 minutes per cycle.

⚡

Hot-Swap Models

9 LLMs pre-configured. Switch from the admin panel without cluster restart. ~30 second model swap time.

🛡️

Three-Layer Backup

Timeshift (hourly automatic) → backup.sh (versioned) → GitLab (offsite). Multiple layers catch different failure modes.

🔒

Air-Gap Ready

3-way network toggle: AIR GAPPED / INTERNAL / FULL. Zero cloud dependencies. All inference happens on-premises.
